# Skylark Linux


Skylark Linux is an independent, open-source Linux distribution focused on making Linux more user-friendly and accessible to everyone.

## Our Vision

We believe Linux should be welcoming to everyone, not just experienced users.

Our goal is to create a familiar, comfortable, and intuitive desktop experience, especially for people transitioning from Windows.

We want to combine the freedom and flexibility of open-source software with the convenience people expect from a modern operating system.

## Our Goals

- Build a user-friendly Linux distribution.
- Provide a familiar and intuitive desktop experience.
- Develop our own tools and technologies.
- Build an independent ecosystem around Skylark Linux.
- Create an open community where everyone can participate.

## Development Status

<em>Early development — work in progress.</em>

Skylark Linux is at the beginning of its journey. We are currently exploring its architecture, design, and foundational technologies.

## Get Involved

We welcome developers, Linux enthusiasts, designers, testers, and anyone interested in open-source software.

You don't need to be an expert to be part of the journey.

More information about contributing will be added as development progresses.
